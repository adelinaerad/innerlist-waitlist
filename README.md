# Innerlist — Waitlist Website

Static export of the Innerlist public waitlist website.

## Deploy with Vercel

Import this repository into Vercel.

Recommended settings:
- Framework Preset: Other
- Root Directory: ./
- Build Command: leave blank
- Output Directory: leave blank
- Install Command: leave blank

The site entry point is `index.html`.

## Important

This is the current frontend prototype/export. Before collecting real applications, the waitlist form should be connected to a persistent backend/database and tested end-to-end.
